# Uttarakhand Temple Locator and Information Portal

A web-based portal designed to provide information about famous temples in Uttarakhand and help users explore temple locations.

## Features

- Explore temple information.
- View temple details.
- Find temple locations using Google Maps integration.
- Add and manage temple records.
- Responsive web interface.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Installation and Setup

1. Clone this repository:

```bash
git clone https://github.com/deepaksingh853284-lab/uttarakhand-temple-portal.git
```

2. Open the project folder:

```bash
cd uttarakhand-temple-portal
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the virtual environment on Windows:

```powershell
.\venv\Scripts\Activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Run the application:

```bash
python app.py
```

7. Open in your browser:

```text
http://127.0.0.1:5000
```
